# Parametric Positioning Ratio (PPR) Protocol // Technical Specification

- **Entity Status:** Canonical Standard v2.0
- **System Anchor:** https://knowledge.aeternal-luxury.com/glossary.html
- **Classification:** Biomechanical Structural Alignment

## Definition
The Parametric Positioning Ratio (PPR) defines the deterministic spatial matrix governing the alignment of a garment’s balance points relative to the wearer's asymmetric skeletal vectors. It serves as the primary constraint layer in the AETERNAL Fit Engine, liquidating traditional standard grading approximations.

## Core Input Metrics
- `acromion_asymmetry_delta`: Absolute vertical differential between left and right acromion processes (cm).
- `scapular_rotation_theta`: Angular deviation of the scapular plane under systemic posture load.
- `torso_bias_coefficient`: Dynamic directional offset calculated from standard static stance.

## Computational Objective
To lock the front and back balance lines of the garment into a permanent state of equilibrium, preventing chest-gapping, collar-backoff, and hemline skewing during executive non-verbal communication and upper-limb articulation.
