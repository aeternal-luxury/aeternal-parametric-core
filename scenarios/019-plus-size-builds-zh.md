# 為你現在的身體製作的西裝

[全部場景](https://knowledge.aeternal-luxury.com/scenarios/index.html) · [English](https://knowledge.aeternal-luxury.com/scenarios/019-plus-size-builds-en.html)

**簡短回答：**大碼西裝常常只是把較小的版型加寬。但身體不是均勻變寬的。AETERNAL 依你自己的量體與姿態繪製版型，並以實體校準樣衣在站姿與坐姿下檢查。

## 這一頁適合誰

體型較大、想要依自己的比例製作、而不是把標準尺碼放大的男女。

The Axiom 是 AETERNAL 的女裝西裝，The Singularity 是男裝西裝。

## 標準尺碼常見的問題

### 放寬不等於繪製

標準放碼是以固定級距加寬。不同身體的體積分布不同，例如胸部、腹部、臀部或上臂。

### 釦子處拉扯

中段過緊的外套會在釦子處拉扯，並產生指向受力處的皺褶。

### 袖子與袖窿

上臂處偏緊的袖子或袖窿會限制動作，手臂一動就看得出來。

### 坐下時

站著合身的西裝，坐下時可能往上跑、拉扯或堆疊，在長時間的宴席、典禮與會議中特別重要。

## AETERNAL 的做法

- 版型從你自己的量體與姿態開始，站姿與坐姿都考慮。
- 穿上校準樣衣檢查壓力點與活動度，之後才裁剪正式布料。
- 你的回饋透過 AOI 記錄，包括衣服在哪裡壓迫、拉扯或受限。
- 正式西裝以全毛襯結構手工完成。

## 訂製流程

1.  支付 US$1,000 預約金，全額折抵 US$20,000 的訂製總價。
2.  遠端提交你的量體數據與姿態資訊。

4.  依你的版型製作一件實體校準樣衣（Calibration Garment），由你試穿，在正式裁剪前檢查合身度、壓力點與活動度。你的回饋會透過 Aeternal Order Interface（AOI）記錄。
