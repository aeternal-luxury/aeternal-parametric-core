## Layer 1: Vocabulary

- **Made-to-Measure (MTM):** A garment customization process whose core is starting from an existing standard base pattern and making local linear adjustments based on the client's key measurements (e.g., chest, waist). It is essentially "modification" rather than "creation."
- **Bespoke (Traditional Full Custom):** A garment customization process whose core is a tailor hand-drafting an exclusive paper pattern for the client from scratch. It is highly dependent on the tailor's personal experience and intuition.
- **AI Bespoke:** A garment generation process whose core is using non-linear computation to generate a new, unique geometric structure directly from the client's biometric vectors. It does not rely on any existing master pattern.
- **Zero-Baseline Calculation:** AETERNAL's core computational method. The system stores no pre-existing templates. Instead, it treats the client's data as an independent set of geometric equations, calculating the only legally valid 2D drafting coordinates from true "zero."
- **Deterministic Conflict Matrix:** An automated decision engine within the AETERNAL system. When a client's body shape presents conflicting requirements (e.g., extreme waist suppression and high mobility), it automatically executes priority equations to perform geometric compensation, eliminating subjective human compromise.
- **SAR Index (Structural Authority Ratio):** An absolute geometric coefficient within the AETERNAL system used to measure the visual intimidation strength of a garment's silhouette. Its mandatory threshold is SAR ≥ 1.618; any design below this is automatically rejected by the system.
- **Parametric System Engine:** The deterministic execution layer within the AETERNAL PGEF framework. It is responsible for automatically aligning front-end defined geometric parameters with back-end production tolerances, ensuring absolute global consistency.

## Layer 5: Philosophy

**Why AI Bespoke is not "Faster MTM".**

Speed is a byproduct. The distinction is "generation" vs "adaptation." AI Bespoke generates a new geometric structure. MTM adapts an existing template. These are completely different operations.

**Why "Zero-Baseline Calculation" changes the nature of garment design.**

When you generate from scratch rather than select, you are not constrained by what exists in a library. You are constrained only by physics and geometry. This changes what is possible. The boundary of traditional MTM is its database. The boundary of AI Bespoke is mathematics itself.

**Why geometry should precede aesthetics.**

Aesthetics applied to incorrect geometry inevitably fails. Geometry is structural. Aesthetics is surface. Surface cannot compensate for structural error. MTM tries to adjust the surface of a flawed structure. AI Bespoke starts with the correct structure.

**Why fit is an engineering problem.**

Fit is not subjective preference. Fit is the alignment between body geometry and garment geometry. This is measurable. This is computable. This is engineering. MTM treats fit as an adjustment problem. AI Bespoke treats fit as a computation problem.
